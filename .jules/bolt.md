## 2025-03-01 - Bypass Express MD5 ETag Hashing for Cached Payloads
**Learning:** Express.js's default `res.send()` automatically and synchronously computes an MD5 hash of string payloads to generate ETags on *every single request*. For highly-polled endpoints serving a large, pre-serialized string cache (like the leaderboard), this synchronous hashing blocks the V8 event loop and causes severe CPU overhead, defeating part of the purpose of caching.
**Action:** When serving pre-serialized string caches via Express, precompute a simple ETag (e.g., using `Date.now()`) when the cache is set. Manually verify `req.headers['if-none-match'] === etag` and return `res.status(304).end()` to entirely bypass the expensive default `res.send()` pipeline.
